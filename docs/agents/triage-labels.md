# Triage Labels

The skills speak in terms of seven canonical triage roles: two category roles and five state roles. This file maps those roles to the actual label strings used in this repo's issue tracker.

| Label in supermatt | Label in our tracker | Meaning                                  |
| ------------------- | --------------------- | ----------------------------------------- |
| `bug`               | `bug`                 | Something broken or at risk — missed deadline, portal error, missing document |
| `enhancement`       | `enhancement`         | A new piece of work — draft a section, request a transcript, build a coding project |
| `needs-triage`      | `needs-triage`        | Needs to be sized/sorted before work starts |
| `needs-info`        | `needs-info`          | Waiting on someone else (recommender, professor, registrar) |
| `ready-for-agent`   | `ready-for-agent`     | Fully specified — Claude can draft or execute this autonomously |
| `ready-for-human`   | `ready-for-human`     | Requires your own judgment or action |
| `wontfix`           | `wontfix`             | Decided not to pursue |

When a skill mentions a role (e.g. "apply the `ready-for-agent` triage label"), use the corresponding label string from the right-hand column.

Edit the right-hand column to match whatever vocabulary you actually use.
